integration_instructions How to connect your own Google Sheet Webhook for an event Click to Expand Code Template

1. Create a Google Sheet for your event and open Extensions > Apps Script.

2. Paste the following script into Code.gs and click Deploy > New Deployment > Web App (Set access to "Anyone"):

function doPost(e) {
  var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
  var data = JSON.parse(e.postData.contents);
  sheet.appendRow([new Date(), data.eventTitle, data.name, data.email, data.academicYear]);
  return ContentService.createTextOutput(JSON.stringify({result: 'success'})).setMimeType(ContentService.MimeType.JSON);
}

3. Copy your Web App URL and add it to the event card's data-sheet-url attribute!
